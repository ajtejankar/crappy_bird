What are the ideas that I want to explore in this project:

1. A single agent evolved and shaped by a community to adapt to its tastes
2. Agents are black boxes with surprising behaviors hidden inside them exploring their weird behaviors can be a fun game
3. We're too focused on serious applications of LLMs, we need some fun in our lives
4. A collaborative system where humans and LLMs generate ideas that neither could have generated on their own
5. A truly long running, stateful game environment for the LLM

The central idea that I am settling on is following:
1. The agent keeps creating new versions of the game constantly
2. It uses explicit user inputs and their usage patterns to decide where to take the game next
3. At all points in time there is a singler playable version of the game

The details can be fine-tuned but these are the core ideas behind the game.
